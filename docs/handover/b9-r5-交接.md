## 6. 用户测出问题时的定位顺序（代理）

1. 页面上那行红字（不是日志）——它来自 Kotlin 的 `error` 码：`port_in_use` / `start_timeout` / `kernel_missing` / `no_config` / `busy` / `start_failed`
2. 日志对话框头部会带「本次生成的配置（前 15 行）」——看 `mode`/`log-level` 是否只出现一次
3. 最新一条内核日志的时间戳：早于安装时间就是旧记录
4. 若 `port_in_use`：`/proc` 里找不到也正常（proot 看不到全表）；看回包 `suggest` 端口的建议，换端口再试
5. 若还是「点开关卡死」：说明又回到了主线程阻塞，检查 `ProxyPlugin.onMethodCall` 的 start/stop 是否仍走 `runOffMain`
