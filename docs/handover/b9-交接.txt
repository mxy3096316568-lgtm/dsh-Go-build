二、这一包新增了什么（b9-1 基础上）
==================================================================
知识库（设置 → 帮助与关于 → 能力控制 → 知识库）
  · 目录：下载/DSH-Go/知识库/，扫描 txt/md/html/csv/json/docx，800 字切块、重叠 100
  · 页面：已收录文档数 / 块数 / 占用 / 上次重建；文档列表（点开看前三块、右边删除要确认）；
    导入文件（文件选择器，多选）；重建索引
  · 索引写在 知识库/.index/index.json，源文件保持可读可改
  · 工具：kb_search / kb_read / kb_import / kb_stats（模型会先搜这里，回答带出处）

爬虫
  · 工具 web_crawl(url, depth, limit, same_domain, render)：同域、限深 ≤3、限量 ≤30、
    遵守 robots.txt、页间 600ms、直取与「内置浏览器渲染」两路
  · 正文写进 知识库/网页/<站点>/<标题>.md，文件头带 url 与抓取时间
  · 增量按 URL+内容哈希：没变不重写；用户删过的页不会被偷偷写回
  · 接口：/kb/put、/kb/crawl（本机 127.0.0.1:47811，和浏览器/云盘/通知同一套 token）

说明书 dsh-go-kb：随引擎启动安装；讲什么时候先搜知识库、怎么引用出处、web_crawl 的边界

导入导出（设置 → 隐私与分享 → 导出存档 / 导入存档）
  · 按分类勾选：会话 / 技能 / 插件 / 设置 / 知识库 / 站点库(默认关) / 通知缓存(默认关) /
    云盘账号(默认关) / 代理订阅(默认关，只记有没有)
  · 知识库导原始文件，导入后自动重建索引；.index 不进包
  · 云盘密码、代理订阅地址（含 token）、API Key 永远不进包
  · 导入先预览（导出时间、分类与文件数、新增/覆盖几个、包里记的「已配置」），
    同名文件可选 覆盖 / 跳过 / 保留两份；导入前自动备份到 下载/DSH-Go/dsh-go-before-import-*.zip
  · manifest.json 带 schemaVersion

授权永久化
  · 审批卡多一个「总是允许（永久）」，只对只读类工具出现（read/list/search/fetch/kb_/notify_ 等）；
    花钱、删除、对外发送类工具不给这个入口
  · 上传确认改三选一：取消 / 允许本次 / 总是允许（这个站点）；已授权站点不再弹
  · 能力控制 → 授权记录：逐条撤销 + 全部清除；每条显示来源、时间、依赖的能力；
    关掉浏览器/文件/云盘/通知开关时，依赖它的授权立刻失效并在列表里标「已失效」
  · 手机操控的免确认仍走它自己的确认方式（每次询问 / 本任务 / 始终免确认）

三、请在这台手机上人工验证（重点）
==================================================================
1. 知识库
   □ 往 下载/DSH-Go/知识库/ 放一个 .md 和一个 .docx，打开页面看「已收录」数目对不对
   □ 点一个文档：能看到前三块文字；点右边垃圾桶：先问一次，删掉后列表少一个、文件也没了
   □ 用页面「导入文件」选一个 txt：被复制进知识库目录，且立刻出现在列表里
   □ 问助手一个只有你文档里才有的问题：应命中并给出文档路径；问个没有的：应说「没找到」
2. 爬虫
   □ 对助手说「把这个页面存进知识库：<某个文章网址>」：抓完 kb_stats 文档数 +1，
     文件出现在 知识库/网页/<站点>/ 下，开头有 url 和抓取时间
   □ 再抓一次同一个页：应报 unchanged，不重写文件
   □ 需要登录的页面用 render=true：会用内置浏览器打开（会占用浏览器标签）
3. 导入导出
   □ 导出存档：只勾「会话」，导出的 zip 里只有 root/.dsh/sessions 和 manifest.json
   □ 导出时勾「知识库」：zip 里有 host/kb/… 的原始文档
   □ 导入那份包：先出预览（新增/覆盖数），选「跳过」后本机文件不变；导入前备份文件出现在下载目录
   □ 确认云盘密码、代理订阅地址不在任何导出文件里（解压看一眼 config/prefs.json）
4. 授权永久化
   □ 让它读一个网页（web_fetch / browser_read）：审批卡上应出现「总是允许（永久）」
   □ 点它 → 之后再让它读网页：不再弹卡
   □ 能力控制 → 授权记录：能看到这条（工具名 + 时间 + 依赖），点撤销后再读网页：重新弹卡
   □ 让它跑 bash 或写文件：审批卡上**不应**出现「总是允许（永久）」
   □ 浏览器里上传一个文件：三选一对话框；选「总是允许（这个站点）」后再传：不再弹
   □ 关掉「浏览器」能力开关 → 授权记录里上传那条应变成「已失效（能力已关）」
5. 回归（b8/b9-1 的老功能）
   □ 内置代理能起、能停，订阅导入不报 duplicate key
   □ 通知中枢能读到通知，关键词规则命中后出现在「通知规则 / 最近命中」
   □ 浏览器：开/关标签、上传、下载、截图、中止加载都正常
   □ 常驻：后台服务在、电池白名单、开机自启（真重启一次手机验证）

五、这一轮踩到的坑（都已在代码/脚本里修好）
==================================================================
1. CI 的 `Flutter 0` 这个 job 同时跑 analyze 和测试：analyze 干净（日志里 "No issues found!"）
   也会因为 73 个既有 golden 像素测试失败而被判红。判断要看 analyze 自己那行日志，
   不要看 job 结论。ship.py 已按日志判断。
2. 取消 CI 用 /cancel 有时不生效（运行一直 in_progress，后面的 run 永远排队）：
   要用 POST /actions/runs/<id>/force-cancel，确认它变成 completed 再排新的。
3. 推送十来个文件时，逐个 POST blob 容易在弱网下断；改用 Git Trees API 的
   inline content（push_quick.py）只要 5 个请求，失败还能重试整次提交，不会留半份。
4. 分析器会拦下这些小东西（都算失败）：
   · BrowserSession 里没有 runJs（那是 BrowserApi 的静态方法）
   · AppIcons 没有 clock（用 bookmark）
   · BytesBuilder 经 dart:io 间接导入已废弃（显式 import dart:typed_data）
   · `if (x != null) x` 在列表里要用 `?x`
5. archive 4.6 的 ArchiveFile 用 readBytes()/writeContent()，不要碰 content 字段。
