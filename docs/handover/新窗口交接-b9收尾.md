## 6. 坑（血泪，逐条都踩过）

1. **CI 的 `Flutter 0` job = analyze + 测试**。job 结论会因为 73 个既有 golden 测试失败而红，
   **不代表 analyze 失败**。判定办法：抓该 job 日志，看到 `No issues found!` 才算干净。
2. **analyze 把 info 级 lint 也当失败**（exit 1）。已踩：`use_build_context_synchronously`
   （内联回调里跨 await 用 build 的 context → 抽成 State 方法）、`use_null_aware_elements`
   （列表里写 `?x`）、`deprecated_export_use`（`BytesBuilder` 要显式 `import 'dart:typed_data'`）。
3. **`unawaited()` 不能包 void**（`WatchService.start()` 踩过）。
4. `BrowserSession` 没有 `runJs`，那是 **`BrowserApi.runJs`** 的静态方法。
5. `AppIcons` 里没有 `clock`（用 `bookmark`）；用之前先 grep 确认。
6. archive 4.6：`ArchiveFile` 用 `readBytes()` / `writeContent()`，没有公开 `content` 字段。
7. **取消 CI 要用 `force-cancel`**：普通 `/cancel` 有时不生效，旧 run 一直 in_progress，
   新 run 永远排队（`ghapi.post('actions/runs/<id>/force-cancel')`）。
8. **推送别一个个 POST blob**：弱网会断，用 `push_quick.py` 的 inline content。
9. 运行时装包被“读不到的 /proc 条目”挡住 → 已修（`a7c6cd18`）。若用户又见到
   「安装未完成 / runtime_upgrade_blocked:running」，先让他**重启手机**再装。
10. 下载目录会被清理：每次出包后立刻把信息同步到 `docs/handover/`，不要只留手机。
